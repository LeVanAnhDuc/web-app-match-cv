## 1. Wizard / navigation

| Khái niệm | Lucide |
|---|---|
| Brand / matching wizard | `wand-2` |
| Bước Job Description | `file-text` |
| Bước CV / Resume / candidate | `user` |
| Bước Review | `eye` |
| Bước Result / hoàn tất | `check-circle` |
| Bước đã done (stepper) | `check` |
| Next / tiến | `arrow-right` / `chevron-right` |
| Back / lùi | `arrow-left` |

## 2. Actions / content

| Khái niệm | Lucide |
|---|---|
| Upload JD | `upload-cloud` |
| Upload CV | `file-plus` |
| Lưu JD | `save` |
| Lưu CV | `bookmark` |

## 3. Status & feedback

| Khái niệm | Lucide |
|---|---|
| Empty-state (chưa có/không kết quả) | `search-x` |
| Điểm mạnh khớp (matched, success) | `circle-check` |
| Gap / thiếu (warning) | `alert-triangle` |
| Gợi ý cải thiện | `lightbulb` / `sparkles` |

## 4. Quy tắc

1 khái niệm → 1 icon nhất quán toàn app. Thêm concept mới → thêm dòng ở đây **trước khi** dùng trong code.
