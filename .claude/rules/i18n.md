Đa ngôn ngữ dùng **nestjs-i18n** — hỗ trợ English (`en`) + Vietnamese (`vi`). Message user-facing luôn đi qua i18n, KHÔNG hardcode chuỗi rải rác.

## Setup (`app.module.ts`)

```ts
I18nModule.forRoot({
  fallbackLanguage: "en",
  loaderOptions: { path: join(__dirname, "/i18n/"), watch: true },
  resolvers: [{ use: QueryResolver, options: ["lang"] }, AcceptLanguageResolver]
});
```

Ngôn ngữ chọn theo `?lang=` hoặc header `Accept-Language`, fallback `en`.

## File dịch JSON (`src/i18n/{en,vi}/<ns>.json`)

- Namespace theo domain: `common.json`, `documents.json`, `matching.json`. Thêm module mới → tạo file JSON **trong CẢ `en/` VÀ `vi/`**.
- Key lỗi gom dưới `errors`: `{ "errors": { "notFound": "...", "fileTooLarge": "..." } }`. Full key khi tra cứu là `<ns>.errors.<name>` (vd `documents.errors.notFound`, `matching.errors.matchNotFound`).
- **`en` và `vi` phải sync** — mỗi key tồn tại ở cả 2 locale, cùng cấu trúc. Thêm/xoá key → làm ở cả 2.

## Per-module helper `i18n-messages.ts`

Mỗi module có `<module>/i18n-messages.ts` export hàm `tX(key, fallback)`:

```ts
import { I18nContext } from "nestjs-i18n";

export function tDoc(key: string, fallback: string): string {
  return I18nContext.current()?.t(key as never) ?? fallback;
}
```

- Tên hàm theo module: `tDoc` (documents), `tMatch` (matching).
- Pattern cố định: `I18nContext.current()?.t(key) ?? fallback` — lấy bản dịch theo request hiện tại, **fallback về chuỗi English** khi gọi ngoài HTTP lifecycle (background/không có context).
- Fallback string phải trùng nội dung key `en` tương ứng (an toàn khi không có context).

## Quy tắc dùng

- Service / pipe / validator báo lỗi user-facing → truyền `tX("<ns>.errors.<key>", "<english fallback>")` làm message cho `HttpException` (xem `errors.md`) hoặc `errorMessage` của file validator.
- Thêm message mới → (1) thêm key vào `en/<ns>.json` + `vi/<ns>.json`, (2) gọi `tX(key, fallback)`.
