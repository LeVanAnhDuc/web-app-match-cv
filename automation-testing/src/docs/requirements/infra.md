# INFRA — Health, Swagger và hạ tầng HTTP dùng chung

- **REQ-INFRA-01** `GET /api/v1/health` là public với mọi trạng thái (ẩn danh, khách, user đăng nhập, cookie phiên hỏng) và trả `200` với body đúng `{"status":"ok"}`; không cần cookie, không tạo khách, không set `mcv_session`. Health chỉ báo app còn sống (liveness), không kiểm datastore.
- **REQ-INFRA-02** Mọi route API nằm dưới tiền tố `/api/v1`; đường dẫn ngoài tiền tố (vd `/health`, `/api/v2/health`) trả `404`.
- **REQ-INFRA-03** Swagger UI phục vụ tại `/api/v1/docs` (`200`, HTML); OpenAPI JSON tại `/api/v1/docs-json` có tiêu đề `match-cv API`, nhóm endpoint theo các tag `auth`, `documents`, `match`, `ai-credentials`, `cover-letters`, `cv-rewrite`, `comparisons`, `me` và liệt kê mọi endpoint đang ship.
- **REQ-INFRA-04** Hợp đồng OpenAPI không lộ bí mật: không ví dụ nào chứa token AI trông như thật, không schema nào có `encryptedKey` / `keyIv` / `keyTag`, `apiKey` chỉ xuất hiện ở DTO request và là `writeOnly`, DTO response của credential không có `apiKey`; `GET /me/export` khai `application/zip` không kèm schema.
- **REQ-INFRA-05** Rate limit toàn cục 100 request / 60 giây mỗi IP (mỗi route) qua `ThrottlerGuard`: response báo `X-RateLimit-Limit: 100`, request vượt ngưỡng trả `429` kèm `Retry-After`; áp cả cho `/health`.
- **REQ-INFRA-06** Mọi response API (thành công lẫn lỗi) mang header bảo mật mặc định của `helmet` (`X-Content-Type-Options: nosniff`, `X-Frame-Options: SAMEORIGIN`, `Content-Security-Policy`, `Strict-Transport-Security`, `Referrer-Policy: no-referrer`, `Cross-Origin-Opener-Policy`) và không có `X-Powered-By`.
- **REQ-INFRA-07** CORS chỉ cho `CLIENT_ORIGIN` (dev `http://localhost:5300`): response và preflight trả `Access-Control-Allow-Origin: <CLIENT_ORIGIN>` kèm `Access-Control-Allow-Credentials: true`; origin khác (kể cả gần giống) không bao giờ được phản hồi lại trong `Access-Control-Allow-Origin` và không có `*`. Trình duyệt ở `CLIENT_ORIGIN` gọi được API kèm cookie.
- **REQ-INFRA-08** Validation toàn cục: field lạ trong body bị loại bỏ (`whitelist`) nên không ghi đè được `id`, chủ sở hữu hay quan hệ; body sai DTO trả `400` với envelope `{statusCode: 400, error: "Bad Request", message: [...]}` nêu tên field sai; JSON hỏng trả `400`, không phải `5xx`.
- **REQ-INFRA-09** Ngôn ngữ message server chọn theo `?lang=` trước, rồi `Accept-Language`, fallback `en`; hỗ trợ `en` và `vi` (vd `GET /me/export?lang=vi` khi chưa đăng nhập → `401` "Cần đăng nhập."); ngôn ngữ không hỗ trợ rơi về `en`.
- **REQ-INFRA-10** Lỗi trả về client (400 / 401 / 404 / 429 / 500) không chứa stack trace, tên bảng, câu SQL hay chi tiết Prisma / đường dẫn file.
- **REQ-INFRA-11** Web client trả lời ở `CLIENT_ORIGIN` (`GET /` < 400), hydrate được, và tải trang gốc không phát sinh response `5xx` nào.
